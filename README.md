# ACCTG Teaching Plan

Plans how many sections of each accounting course we need each term and who teaches them, for the University of Utah School of Accounting.

## Use it

1. Open `index.html` in Chrome or Edge (or the GitHub Pages link).
2. Click **Open file** and choose your plan file (`.json`).
3. Make changes, then click **Save** (or Ctrl+S). The file is updated in place.

This page holds no data. Your plan file does, so keep it somewhere backed up and out of this repo.

## Tabs

- **Assignments**: every planned section as a slot. Red "Open" slots need an instructor. The side panel shows each person's load against their contract.
- **Section plan**: how many sections of each course you expect each term.
- **Faculty**: people, tracks, and contracts for the selected year.
- **Courses**: the one course list everything else uses, with credit hours.
- **Checks**: open sections and other problems, plus things worth a second look.
